# Post by @qihang_zeng6688 on X

> 来源: https://x.com/qihang_zeng6688/status/2121500953170092128

## 摘要
Obsidian CEO Steph Ango（kepano）公开了自己使用的知识库 Vault 模板，作者据此整理了 7 个相关 GitHub 项目：40 Questions（年度复盘问题清单）、Minimal 主题、obsidian-sample-plugin（官方插件开发模板）、kepano-obsidian（个人知识库模板，非其完整私人库）、Flexoki 写作与编程配色、obsidian-releases（社区插件与主题目录，不含源码）、JSON Canvas（开放画布文件格式）。建议新手先看知识库模板和 Minimal 主题，先动笔写笔记，用一段时间后再按自身需求调整分类和插件，而非一开始纠结结构。评论区也指出：真正的难点是持续填充知识库内容。

---

窝趣！Obsidian 的 CEO 把自己用的知识库模板放到 GitHub 上了。

想用 Obsidian 搭建个人知识库，但不知道怎么分类、怎么组织笔记的朋友，可以先看看他的模板。

除了知识库模板，Obsidian 官方和 CEO Steph Ango（kepano）还分享了几个相关项目，我整理了 7 个：

1、40 Questions：年度复盘问题

kepano 整理的一份问题清单，用来回顾自己过去一年或一个阶段的生活。

不知道年度复盘从哪里开始的朋友，可以挑几个问题，结合自己的日记和笔记来回答。

http://github.com/kepano/40-questions…

2、Minimal：Obsidian 主题

一个简洁、可自定义的 Obsidian 主题。喜欢干净一点的笔记界面，可以在 Obsidian 的主题市场里搜索 Minimal。

http://github.com/kepano/obsidian-minimal…

3、obsidian-sample-plugin：官方插件模板

如果你用 Obsidian 的时候，发现现有插件满足不了自己的需求，可以拿这个官方模板作为起点，尝试开发一个自己的插件。

也可以把仓库交给 Codex，让它先帮你解释项目结构和开发步骤。

http://github.com/obsidianmd/obsidian-sample-plugin…

4、kepano-obsidian：个人知识库模板

Obsidian 的 CEO 把自己使用的 Vault 模板放到了 GitHub 上。里面展示了他组织笔记和资料的方式，可以下载下来研究，再根据自己的需求修改。

注意，这是公开的模板，不是他完整的私人知识库。

http://github.com/kepano/kepano-obsidian…

5、Flexoki：写作和编程配色

kepano 为写作和代码设计的一套配色。如果你想调整 Obsidian、编辑器或者自己网站的颜色，可以参考这套方案。

http://github.com/kepano/flexoki

6、obsidian-releases：插件和主题目录

这里维护了 Obsidian 的社区插件目录、主题目录和公开版本信息。

想找插件、研究社区都有哪些工具，可以从这里入手。仓库本身不包含 Obsidian 的源代码。

http://github.com/obsidianmd/obsidian-releases…

7、JSON Canvas：开放式画布格式

Obsidian 的 Canvas 可以用来把笔记、图片和想法放到一张画布上。

JSON Canvas 是用于保存这些画布数据的开放文件格式。对想研究画布工具，或者希望了解画布数据怎么存储的朋友，可以看看这个项目。

http://github.com/obsidianmd/jsoncanvas…

如果你是刚开始用 Obsidian，我建议先看知识库模板和 Minimal 主题：先把笔记写起来，用一段时间之后，再根据自己的需求调整分类和插件。 https://x.com/rvaniaaaa/status/2119056971298980112/video/1…
