# 剪藏工作流说明

> 配置来源:jexchan《如何用好 Obsidian Web Clipper 这个神器》(2026-11-20)

## 流程

外部信息 → Web Clipper 剪藏 → References 参考资料池 → 阅读与判断 → 知识卡片 → 产出

- 剪藏统一进入:`05_References/01_Inbox/`
- 提炼后的知识卡片放入:`04_Knowledge/00_Cards/`
- 原文剪藏是**材料**,知识卡片是经过理解、改写、连接之后的**资产**,二者分开存放。

## status 状态(每篇剪藏的 frontmatter 属性)

| 状态 | 含义 |
| --- | --- |
| `inbox` | 刚剪藏进来,未读 |
| `reading` | 读过,还没提炼 |
| `extracted` | 已提炼成卡片(把笔记移到 05_References 对应主题文件夹) |
| `archived` | 不再处理,留作参考 |

查看待处理:打开 [[剪藏待处理.base]](Bases 表格,按状态分视图)。
也可以直接问 AI:"我的剪藏内容有哪些待处理?"——按 `05_References` 下 `status: inbox` 查询即可。

## 四个剪藏模板

| 模板 | 用途 |
| --- | --- |
| `content` | 通用文章剪藏,AI 自动摘要 + 打标签 |
| `content-deepreading` | 深度阅读:摘要 / 三个要点 / 关键概念(Nick Milo 三层结构) |
| `video` | 视频页(YouTube/B站自动触发),含转录文本 |
| `translation` | 剪藏同时全文翻译成中文,原文附后 |

文件名规则:`clip_{{title|kebab|safe_name}}` → 如 `clip_my-vision-a-forgotten-history.md`。

## AI 解释器

走本机 new-api 网关(`http://127.0.0.1:3000/v1/chat/completions`,密钥仅限本机请求):

- **Qwen4 Max**(`qwen4-max`,默认,自带深度思考)
- **Qwen3.8 Flash**(`qwen3.8-flash`,备用,快)
- **DeepSeek V4.1 Flash**(`deepseek-v4.1-flash`,备用)
- **Gemini 3.1 Flash Lite**(`gemini-3.1-flash-lite-preview`,备用)

> 注:网关没有独立的 "qwen4-max-high" 模型;Clipper 也不发送推理强度参数,
> 思考深度由上游渠道决定。想要固定 high 需在 new-api 渠道的参数覆盖里设 `reasoning_effort: high`(会影响所有走该渠道的请求)。

剪藏弹窗里选模板 → 选解释器 → 点「解释」,AI 处理完再「添加到 Obsidian」。

## 阅读模式

浏览器里按 `Shift + Alt + R`(推文中的 Shift+Option+r 是 Mac 键位)进入 Obsidian Reader 干净阅读页;YouTube 视频还能显示带时间戳的转录。
不装扩展也能用:在任意网址前加 `defuddle.md/` 直接得到干净 Markdown。
